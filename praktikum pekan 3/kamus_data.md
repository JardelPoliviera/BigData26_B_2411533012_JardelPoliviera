# Kamus Data - Dataset Akhir Terkurasi (`trips_bersih_gabungan`)

| Nama Kolom              | Tipe Data        | Satuan              | Sumber Data                | Aturan Validitas / Deskripsi                                                  | Cara Penanganan Nilai Hilang / Transformasi                       |
| :---------------------- | :--------------- | :------------------ | :------------------------- | :---------------------------------------------------------------------------- | :---------------------------------------------------------------- |
| `tpep_pickup_datetime`  | `datetime64[us]` | YYYY-MM-DD HH:MM:SS | TLC Yellow Taxi            | Waktu penumpang naik taksi. Harus berada pada periode bulan bersangkutan.     | Tidak boleh ada hilang (Wajib ada).                               |
| `tpep_dropoff_datetime` | `datetime64[us]` | YYYY-MM-DD HH:MM:SS | TLC Yellow Taxi            | Waktu penumpang turun taksi. Harus > `tpep_pickup_datetime`.                  | Tidak boleh ada hilang (Wajib ada).                               |
| `passenger_count`       | `float64`        | Orang               | TLC Yellow Taxi            | Jumlah penumpang dalam taksi.                                                 | Diisi (_imputation_) dengan nilai median per kelompok jam pickup. |
| `trip_distance`         | `float64`        | Mil                 | TLC Yellow Taxi            | Jarak perjalanan (validitas: 0.01 – 100 mil).                                 | Baris di luar rentang valid dibuang (_filtering_).                |
| `PULocationID`          | `int64`          | ID Zona             | TLC Yellow Taxi            | ID lokasi pickup (1–263). Harus terdaftar di tabel zona.                      | Baris dengan ID tidak valid dibuang.                              |
| `DOLocationID`          | `int64`          | ID Zona             | TLC Yellow Taxi            | ID lokasi dropoff (1–263). Harus terdaftar di tabel zona.                     | Baris dengan ID tidak valid dibuang.                              |
| `payment_type`          | `int64`          | Kode Angka          | TLC Yellow Taxi            | Kode jenis pembayaran (1=Kredit, 2=Tunai, dll).                               | Kategori tidak dikenal dipetakan ke _Unknown_.                    |
| `fare_amount`           | `float64`        | USD                 | TLC Yellow Taxi            | Tarif dasar perjalanan berdasarkan argometer.                                 | Baris dengan nilai <= 0 dibuang.                                  |
| `tip_amount`            | `float64`        | USD                 | TLC Yellow Taxi            | Jumlah tip yang diberikan penumpang (harus >= 0).                             | Nilai negatif dibuang/disesuaikan.                                |
| `total_amount`          | `float64`        | USD                 | TLC Yellow Taxi            | Total biaya yang dibayar penumpang (harus > 0).                               | Baris dengan total <= 0 dibuang.                                  |
| `durasi_menit`          | `float64`        | Menit               | Turunan                    | Durasi perjalanan (`dropoff - pickup` dalam menit). Validitas: 1 – 180 menit. | Baris di luar rentang 1-180 menit dibuang.                        |
| `jam`                   | `int32`          | Jam (0-23)          | Turunan                    | Jam saat penumpang naik (`pickup.dt.hour`).                                   | Dihitung otomatis dari `tpep_pickup_datetime`.                    |
| `borough_naik`          | `object`         | Nama Wilayah        | Taxi Zone Lookup           | Nama borough tempat penumpang naik taksi.                                     | Dilakukan _left join_; jika tidak cocok diisi `NaN`/`Unknown`.    |
| `nama_pembayaran`       | `object`         | Teks                | SQLite (`tarif_referensi`) | Nama jenis pembayaran (misal: "Kartu kredit", "Tunai").                       | Dilakukan _left join_ berdasarkan `payment_type`.                 |
| `jam_mulai`             | `datetime64[us]` | YYYY-MM-DD HH:00    | Turunan                    | Waktu pickup yang dibulatkan ke jam terdekat (`dt.floor("h")`).               | Digunakan sebagai kunci join data cuaca.                          |
| `suhu_c`                | `float64`        | Celsius (°C)        | Open-Meteo API             | Suhu udara per jam di New York.                                               | Dilakukan _left join_ berbasis `jam_mulai`.                       |
| `hujan_mm`              | `float64`        | mm                  | Open-Meteo API             | Curah hujan per jam.                                                          | Jika _null/NaN_, diisi dengan `0.0`.                              |
| `tanggal`               | `object`         | YYYY-MM-DD          | Turunan                    | Tanggal perjalanan (`dt.date.astype(str)`).                                   | Digunakan untuk partisi data.                                     |
| `nama_libur`            | `object`         | Teks                | Nager.Date API             | Nama hari libur publik US (jika ada).                                         | Jika bukan hari libur, diisi `"Bukan Libur"`.                     |
| `is_libur`              | `int8`           | Biner (0 / 1)       | Nager.Date API             | Indikator hari libur (1 jika libur, 0 jika tidak).                            | Jika _null/NaN_, diisi dengan `0`.                                |
